# Political Private Network Platform (PPN)

Enterprise Private Political Network Platform built with **React**, **TypeScript**, **Vite**, **Next.js App Router**, and **Tailwind CSS**.

## 🚀 Key Features (30 Complete Modules)

1. **Global Application Shell & Theme Switcher**
2. **Public Landing, About, Features, Security & Contact Suite**
3. **7-Step Multi-Step Verification & Registration Wizard**
4. **Member Dashboard & Interactive Statistics**
5. **Organization Explorer & Member Directory (Windows/VS Code Tree View)**
6. **Enterprise Chat Messenger (WhatsApp/Slack/Teams Style)**
7. **Voice & Video Call System (HD Call Overlay & Draggable Mini Window)**
8. **Meeting & Conference Suite (Schedule, Attendance, Live Room)**
9. **Enterprise AI Assistant (ChatGPT/Claude/Gemini Style)**
10. **News Feed & Social Network (Reactions, Polls, Stories)**
11. **Document Vault & Digital Library (Google Drive Style)**
12. **Task & Workflow Management (Kanban Board & List Views)**
13. **Event Management System (QR Check-in & Attendance)**
14. **E-Learning & Training Center (Courses, Lessons, Quizzes)**
15. **Poll & Survey System (Interactive Voting & Live Charts)**
16. **Reports & Analytics Center (Power BI Style Dashboards)**
17. **Notification & Emergency Communication Center**
18. **Digital Member ID & Smart Identity Wallet (3D Watermark & QR)**
19. **Security Operations Center - SOC (Audit Logs & Active Sessions)**
20. **Organization Management System (Committee Hierarchies)**
21. **Member Verification & Approval Queue (7-Step Admin Review)**
22. **Admin Control Center (Role-Based Admin Dashboards)**
23. **Super Admin Control Center (Server Health & Infrastructure)**
24. **Media Center & Digital Asset Management**
25. **Help Desk & Support Center (Zendesk Style Ticketing)**
26. **Master Calendar & Resource Scheduler**
27. **Universal Global Search & Smart Discovery Center**
28. **Activity Timeline & Audit Explorer (Splunk/Kibana Style)**
29. **System Settings & Platform Configuration**
30. **Developer Center & API Integration Hub (Swagger/Postman Style)**
31. **Interactive Demo Mode & Client Presentation Center**

## 🛠 Local Setup & Development

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build
```

---

## 🌐 One-Click Deployment

### Netlify Deployment
* Import repository to Netlify.
* Build command: `npm run build`
* Publish directory: `dist` or `.next`

### Vercel Deployment
* Import repository to Vercel.
* Framework Preset: `Vite` or `Next.js`
* Build command: `npm run build`
